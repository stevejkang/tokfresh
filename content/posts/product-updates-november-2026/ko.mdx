이번 달 TokFresh에 새로 추가된 기능을 소개합니다.

## Cloudflare 계정 하나로 여러 Claude 계정 운영

이제 Claude 계정마다 이메일 기반 이름의 워커가 따로 만들어집니다. Claude 계정을 여러 개 쓰신다면 계정마다 셋업을 한 번씩 실행하면 됩니다. 모두 같은 Cloudflare 계정 안에서 독립적으로 동작합니다.

같은 Claude 계정으로 셋업을 다시 실행하면 새 워커를 만들지 않고 그 계정의 워커를 업데이트합니다. 스케줄을 바꾸는 방법은 이전과 같습니다.

## 연결한 계정 확인

Claude를 연결하면 셋업 화면에 로그인한 계정 이메일이 표시됩니다. 어떤 계정의 워커인지 헷갈릴 일이 없습니다.

## 재로그인 알림

Claude 로그인은 약 28일이 지나면 만료되고, 그 뒤로는 토큰을 갱신할 수 없어 셋업을 다시 진행해야 합니다. TokFresh는 로그인 정보를 보관하지 않기 때문에 대신 연장해 드릴 수 없습니다.

그래서 셋업 중에 알림 받을 이메일을 입력받습니다. 로그인이 만료되기 며칠 전에 셋업 링크가 담긴 메일을 한 번 보내드립니다. 기본값은 Claude 계정 이메일이고, 다른 주소를 쓰거나 알림을 받지 않도록 선택할 수도 있습니다.

## 새 모델 적용

워커가 Claude Haiku 4.5 대신 Claude Haiku 5.5로 요청을 보냅니다. Haiku 5.5의 API 정가는 Haiku 4.5의 10분의 1입니다. 입력 토큰은 100만 개당 $1.00에서 $0.10으로, 출력 토큰은 $5.00에서 $0.50으로 내려갔습니다. 원래도 아주 작은 요청이었지만, 이제 플랜 사용량을 그보다 더 적게 씁니다.

2026년 5월 15일 이후 셋업 페이지에서 배포한 워커는 모델이 코드에 고정되어 있지 않습니다(동적으로 적용됩니다). 실행할 때마다 TokFresh에 사용할 모델을 물어보기 때문에 이미 Haiku 5.5로 바뀌었고, 따로 하실 일은 없습니다. 그 전에 셋업하셨다면 셋업을 한 번 다시 실행해 최신 워커로 바꿔 주세요.
